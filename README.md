# Astra-Cesbo-Free
Astra Cesbo Auto Install Script
### Astra installation

    **Fresh Server is Recommended**
    Ubuntu 14 & 16 tested
    Login as root
    then type/Copy-Paste the following Commands:

    cd ~/ && https://github.com/alvision07/Astra-Cesbo-Free/blob/main/astra_install.sh
    chmod 755 astra_install.sh
    ./astra_install.sh
